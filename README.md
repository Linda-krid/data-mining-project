\# Data Mining Project



\## 📌 Description



This project was developed as part of a Data Mining course.



The objective is to apply different machine learning techniques to an insurance dataset and compare their performance.



\## 📊 Dataset



The project uses an insurance dataset containing information used for prediction and analysis.



\## 🤖 Machine Learning Models



Several machine learning algorithms were implemented and evaluated:



\- Decision Tree

\- K-Nearest Neighbors (KNN)

\- Logistic Regression

\- Multi-Layer Perceptron (MLP)

\- Random Forest

\- Support Vector Machine (SVM)



\## 🛠️ Technologies



\- Python

\- Pandas

\- NumPy

\- Scikit-learn

\- Matplotlib

\- Jupyter Notebook
